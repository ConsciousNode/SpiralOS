# Hummingbird 1.1 Hardware Specification (`HARDWARE.md`)

This document specifies the hardware, CPU features, timing model, I/O ports, and BIOS services emulated in **Hummingbird 1.1** (including the **StudioNet** virtual network interface added for SpiralOS), as well as what is intentionally absent.

## 1. Emulated Hardware Summary

| Component | Emulated Model / Specification | Details |
| :--- | :--- | :--- |
| **CPU** | Intel Pentium (i586), Family 5, Model 2, Stepping 12 (`0x052C`) | Vendor `"GenuineIntel"`, configurable clock (default `100 MHz`), 32-bit integer unit + x87 FPU, `RDTSC` (virtual cycles), `MSR`, `CMPXCHG8B`, 4 KB & 4 MB `PSE` paging, `PGE`, 286+ `AAA`/`AAS` semantics (`140/140` on `cpu-oracle.js`). **No MMX, no SSE, no CMOV in CPUID, no APIC.** |
| **FPU** | Integrated i587 / x87 FPU | 80-bit extended precision (`ST(0)..ST(7)`), status/control/tag words, `FNSAVE`/`FRSTOR`/`FNSTENV`/`FLDENV`, `CR0.EM`/`CR0.TS` `#NM` (Vector 7) support |
| **RAM** | 64 MB default (configurable 16–256 MB) | Contiguous physical RAM with A20 gate mask (`0xFFEFFFFF` when disabled), VGA text/gfx window (`0xA0000..0xBFFFF`), write-protected BIOS ROM (`0xE0000..0xFFFFF`), and E820 memory map |
| **Video (VGA + VBE)** | Standard VGA Text/Planar + VBE 3.0 PCI Adapter (`00:02.0`, Vendor `1234:1111`) | 80×25 16-color text mode (`03h`) at `0xB8000` with CP437 8×16 font, Mode `12h` (640×480×16 planar) / `13h` (320×200×256), 60 Hz vertical/horizontal retrace at `0x3DA`/`0x3BA` derived from virtual time, and Bochs/VBE 3.0 Linear Framebuffer (16 MB at `0xE0000000`) supporting `1024×768×32` (`0x118`), `800×600×32` (`0x115`), `640×480×32` (`0x112`), and 16-bpp modes (`0x117`, `0x114`, `0x111`) |
| **System Timer** | Intel 8254 PIT (`0x40..0x43`) + System Control Port B (`0x61`) | Driven by the `1.193182 MHz` oscillator derived from `cpu.cycles`. Supports Channels 0, 1, and 2, Modes `0..5`, binary/BCD counting, counter latch, read-back command (`0xC0..0xDF`), and lobyte/hibyte access. Channel 0 output fires `IRQ0`; Channel 2 gate (`bit 0`), speaker enable (`bit 1`), refresh toggle (`bit 4`, every `15.085 µs` / 18 PIT ticks), and Channel 2 output (`bit 5`) are exposed on port `0x61` |
| **PC Speaker** | WebAudio Oscillator (`PCSpeakerAudio`) | Synthesizes square/low-pass tone at `1193182 / pit.reload[2]` Hz when `port 0x61 & 0x03 === 0x03` in browser real-time mode (muted in headless and deterministic runs) |
| **Real-Time Clock** | Motorola MC146818 CMOS/RTC (`0x70..0x71`) | 128-byte NVRAM, BCD/binary time & date registers (`0x00..0x09`) advancing at `1 s` per `cpuFreqHz` virtual cycles, status registers `A..D`, floppy drive type (`0x10 = 0x40` for 1.44 MB 3.5"), base/extended memory size registers (`0x15..0x18`, `0x30..0x35`) |
| **Interrupt Controller** | Dual 8259A PIC (Master `0x20..0x21`, Slave `0xA0..0xA1`) | ICW1–ICW4 initialization, OCW1–OCW3 (`IRR`/`ISR` reads, specific & non-specific EOI), slave cascade on IRQ2 |
| **DMA Controller** | Intel 8237A DMA (`0x00..0x0F`, Page Registers `0x80..0x8F`) | 4-channel 8-bit DMA controller with full Channel 2 support (`addr 0x04`, `count 0x05`, `mask 0x0A`, `mode 0x0B`, `flip-flop 0x0C`, `master clear 0x0D`, `page 0x81`) for 24-bit physical floppy DMA transfers |
| **Floppy Controller** | Intel 82077AA FDC (`0x3F0..0x3F7`) + `IRQ6` | DOR (`0x3F2`), MSR (`0x3F4`), Data FIFO (`0x3F5`), DIR (`0x3F7`), CCR (`0x3F7`). Executes `READ DATA` (`0x06`), `WRITE DATA` (`0x05`), `READ DELETED DATA` (`0x0C`), `READ TRACK` (`0x02`), `READ ID` (`0x0A`), `RECALIBRATE` (`0x07`), `SEEK` (`0x0F`), `SENSE INTERRUPT STATUS` (`0x08`), `SENSE DRIVE STATUS` (`0x04`), `SPECIFY` (`0x03`), `VERSION` (`0x10` -> `0x90`), `CONFIGURE` (`0x13`), `DUMPREG` (`0x0E`), `PERPENDICULAR MODE` (`0x12`), and `LOCK` (`0x14`) with DMA Channel 2 transfers and `IRQ6` (`INT 0Eh`) completion |
| **Keyboard & Mouse** | Intel 8042 PS/2 Controller (`0x60`, `0x64`) | AT Keyboard (Set 1 scancodes on `IRQ1`, translated to BIOS key words in BDA `0040:001E..003D` with Shift/Ctrl/Alt/Caps state at `0040:0017..0018`) + PS/2 Auxiliary Mouse (3-byte and 4-byte IntelliMouse ID `0x03`/`0x04` packets on `IRQ12`, ISR-gated 1-byte-per-IRQ delivery), A20 & CPU reset commands (`0xD1`, `0xFE`) |
| **StudioNet NIC** | ConsciousNode StudioNet Virtual NIC (`0x02A0..0x02AF`) + `IRQ10` | Magic `0x4E53` (`'SN'`) at `0x02A0`, Status/Command at `0x02A2` (`1=TX_SEND`, `2=RX_POP`, `3=RESET`, `4=IRQ_EN`), 16-bit Station Node ID at `0x02A4` (default `0x0201`), Frame Length at `0x02A6`, 32-bit Physical DMA Address at `0x02A8..0x02AB`, PIO FIFO at `0x02AC`, TX/RX packet counters at `0x02AD..0x02AF`. Backed by `BroadcastChannel("studionet-v1")` and `__STUDIONET_SWITCH`. |
| **PCI Bus** | PCI Configuration Mechanism #1 (`0xCF8..0xCFF`) | Bus 0, Dev 0 (`8086:1237` Intel 440FX Host Bridge) and Bus 0, Dev 2 (`1234:1111` VBE VGA Controller with BAR0 `0xE0000008`). All other BDFs return `0xFFFFFFFF` |
| **Power Management** | APM 1.2 BIOS (`INT 15h AH=53h`) | Supports real-mode and 32-bit protected-mode installation check, connect (`5301h..5303h`), driver version `1.2` (`530Eh`), and power-off (`5307h BX=1 CX=3`) |
| **Debug Console** | Port `0xE9` + dynamic KolibriOS `msg_board_data` mirror | Captures `OUT 0xE9, AL` and dynamically probes & mirrors kernel `DEBUGF` messages |

## 2. Emulated BIOS Interrupt Services

| Vector | Functions Implemented | Behavior |
| :--- | :--- | :--- |
| **`INT 08h`** | System Timer ISR (`F000:E040`) | Triggered by PIT Channel 0 (`IRQ0`) at the OS-programmed rate (default `18.2065 Hz` when `reload = 65536`); increments 32-bit BDA tick counter at `0040:006C`, handles 24-hour rollover (`0x001800B0`) with `0040:0070`, invokes `INT 1Ch`, and sends EOI (`0x20`) to Master PIC |
| **`INT 09h`** | Keyboard ISR (`F000:E048`) | Reads Set 1 scancode from port `0x60`, updates modifier flags in BDA `0040:0017..0018`, translates make codes and `0xE0`-prefixed extended keys into 16-bit `(scancode << 8) \| ascii` words in the BDA circular buffer (`0040:001E..003D`), and sends EOI to Master PIC |
| **`INT 0Eh`** | Floppy Disk ISR (`F000:E070`) | Triggered by 82077AA FDC `IRQ6`; sets bit 7 of BDA floppy recalibrate/interrupt status byte at `0040:003E` (`0x80`) and sends EOI (`0x20`) to Master PIC |
| **`INT 10h`** | VGA & VBE 3.0 Video BIOS | `AH=00h` (set mode), `01h` (cursor shape), `02h` (set cursor pos), `03h` (get cursor pos), `06h/07h` (scroll up/down), `08h/09h/0Ah` (read/write char/attr), `0Eh` (teletype output), `0Fh` (get video mode), `11h` (font info), `12h` (EGA info), `13h` (write string), `4F00h..4F07h` (VBE 3.0 LFB at `0xE0000000`) |
| **`INT 11h` / `12h`** | Equipment Word / Base Memory Size | Returns BDA `0x0410` (`0x0023`) and `0x0413` (`639` KB) |
| **`INT 13h`** | Floppy Disk Services (Drive `0x00`) | `AH=00h` (reset), `01h` (status), `02h` (read CHS sectors), `03h` (write CHS sectors), `08h` (get drive parameters), `15h` (get disk type), `41h` (EDD check returns `CF=1` for floppy). Hard drives (`DL >= 0x80`) return `CF=1` |
| **`INT 15h`** | System Services | `AX=E820h` (SMAP memory map), `AX=E801h`, `AH=88h` (extended memory size), `AX=2400h..2403h` (A20 gate control), `AH=87h` (protected-mode block move), `AH=53h` (APM 1.2), `AH=C0h` (system config), `AH=86h` (microsecond wait) |
| **`INT 16h`** | Keyboard Services | Drains pending 8042 keyboard bytes via `INT 09h` translation first; `AH=00h/10h` (blocking read key; yields via `STI; HLT` stub so `INT 08h` timer ticks advance via `HLT` skip-ahead), `AH=01h/11h` (non-blocking peek key with `ZF`), `AH=02h/12h` (shift flags) |
| **`INT 19h`** | Bootstrap Loader | Loads sector 0 of floppy to `0000:7C00` and jumps to `0000:7C00` |
| **`INT 1Ah`** | Time-of-Day & PCI BIOS v2.10 | `AH=00h..05h` (BDA tick counter & BCD RTC time/date derived from virtual clock), `AX=B101h..B10Dh` (PCI BIOS v2.10) |
