# SpiralOS 1.2 — Physical Hardware Bring-Up Checklist (`HARDWARE-CHECKLIST.md`)

**Target Machine:** Core 2 Duo–era laptop (e.g. Toshiba Satellite / Tecra) booting from USB flash drive in Legacy BIOS / CSM mode.

1. **Write Image & Verify SHA-256**: Write `spiralos.img` (`1,474,560` bytes) directly to the raw USB block device (`dd if=spiralos.img of=/dev/sdX bs=512 conv=fsync`) and read back the first `2,880` sectors to confirm the SHA-256 matches the `Full 1.44 MB Image SHA-256` printed by `node tools/report-figures.js`.
2. **Stage 1 & Stage 2 Boot Banner**: Boot the laptop from the USB stick in Legacy BIOS mode; verify the VGA text banner `SpiralOS 1.1` briefly appears at row 2 before switching into VBE graphics mode. *If it hangs in text mode:* record the last visible text line and check whether BIOS `INT 13h` `DL` drive number (`[0x7DFC]`) or VBE `INT 10h AX=4F02h` returned an error.
3. **VBE Framebuffer Pitch & Vertical Centering (`F3`)**: Confirm the `320×200` pixel-doubled (`640×400`) desktop appears centered vertically inside the `640×480` panel with clean `40`-pixel top/bottom black borders and zero diagonal shear or vertical stripes. *If skewed or striped:* record the laptop VBE BIOS `BytesPerScanLine` (`[0x5010]`) and `BitsPerPixel` (`[0x5019]`).
4. **PS/2 Trackpad / Mouse Pointer Handshake (`F2`)**: Move a finger across the internal PS/2 trackpad and click the top-left `[Spiral]` button (`x=2..54, y=1..11`); verify the pointer moves smoothly without jumping on the first packet and the launcher menu opens. *If the pointer does not move:* record whether the trackpad requires an additional vendor knock sequence or longer reset settle delay after `0xD4 0xFF`.
5. **Keyboard & Timeout Fallback (`F2`)**: Press `h`, `e`, `l`, `p`, `Enter` in the focused `SpiralSh` window; confirm keystrokes register immediately with no input lag or dropped characters even if no external mouse is attached. *If keys drop or repeat:* record the `0x64` status register byte and check whether BIOS USB Legacy Support is intercepting port `0x60`/`0x64`.
6. **Shell Soft-Wrapping & Horizontal Input Scrolling (`F1`)**: In `SpiralSh`, run `help`, run `lines` (30 lines of 80-character output), and type a 60+ character line without pressing `Enter`; confirm all output wraps cleanly inside the black terminal rectangle, the newest lines and `$ ` prompt stay visible at the bottom, and the input line scrolls horizontally without drawing a single pixel outside the window border. *If any character clips or spills:* record the window `(w, h)` and command used.
7. **Window Resize & All-App Containment (`F1`)**: Open `SpiralFiles`, `SpiralEdit`, `SpiralCalc`, `SpiralChat`, and `SpiralWeb` from the `[Spiral]` menu and drag each window's bottom-right resize grip to minimum (`80×50`) and maximum (`320×172`) size; confirm title bars, taskbar buttons, filenames, and widgets stay strictly inside their window frames. *If any widget overflows:* record the app name and window dimensions.
8. **BIOS `INT 13h` Real-Mode Thunk Persistence**: In `SpiralFiles`, click `[+New]` to create `/home/note.txt` (triggering the 16-bit Real-Mode `INT 13h AH=03h` write thunk at `0x7F40` since booted from USB drive `>= 0x80`), then run `reboot` in `SpiralSh`; confirm the machine returns cleanly to 32-bit Protected Mode after the save and `/home/note.txt` is present in `SpiralFiles` after reboot. *If save fails or hangs on thunk return:* record whether the BIOS modified `CR0`, `GDTR`, or segment registers during `INT 13h AH=03h`.
